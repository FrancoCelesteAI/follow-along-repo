# The prompts

Type these one at a time. Look at the result before you type the next one.

Using your own business? Change the facts in `business-facts.md` first, and change the six questions in Prompt 5.

## Prompt 1. Build it

```
I'm not a developer. Read business-facts.md, then build a one-page website for that business. Sections: what we do, what a day here looks like, prices, and how to book a meet-and-greet. Plain HTML and CSS in this folder so I can open it in my browser. Use simple placeholder images I can replace with real photos later. Do not invent reviews, awards or numbers. When you finish, tell me in plain words what you made.
```

## Prompt 2. Look at it

```
Open the page in my browser so I can look at it.
```

Way A: ask the chat how to save the code as a file and open it.

## Prompt 3. Fix what is off

Use your own words. This is the pattern:

```
Two things are off. [Say the first thing you see.] [Say the second.] Fix both and tell me what you changed.
```

Example: "Two things are off. The prices are hard to find. The button at the top does nothing. Fix both and tell me what you changed."

## Prompt 4. Check it on a phone

```
Check the page at phone width. Fix anything that runs off the side of the screen or is too small to tap. Then tell me what you fixed.
```

## Prompt 5. Make the website answer your customers

```
Add a section called "Questions we get every day" with short, friendly answers to these six: What are your hours? How much is a day? Does my dog need shots? What is the meet-and-greet? What do I bring? What if my dog doesn't get along with others? Use only the facts in business-facts.md. If a fact is missing, write "ask us" instead of making something up.
```
