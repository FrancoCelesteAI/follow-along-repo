# Setup for Way B (about 10 minutes, once)

This gets you the same kind of setup used in the videos, the short way. No command line.

## What you need

- A Windows or Mac computer.
- A paid Claude plan. Claude Code, the part that builds files, is not included in the free plan. Check the current plans and prices on [Claude's pricing page](https://claude.com/pricing) before you buy anything.

## Steps

1. **Install the Claude desktop app.** Follow Anthropic's own guide: [Claude Code desktop quickstart](https://code.claude.com/docs/en/desktop-quickstart). It is a normal installer.
2. **Open the app and sign in.**
3. **Download a folder from this page.** Green **Code** button, **Download ZIP**, open the zip, drag the folder (for example `01-website-in-one-sitting`) to your Desktop.
4. **In the app, open the Code tab and choose "Open folder".** Pick the folder on your Desktop.
5. **Type the first prompt** from that folder's `PROMPTS.md`, or type `/site-check` to see a skill run.

The app will ask your permission before it creates or changes files. Read what it asks. Say yes to things that stay inside the folder you opened.

## If something does not match

Apps change. If a button here is named differently in your version, trust the official guide linked in step 1 over this page, and tell me in the comments of the video so I can fix it.

## Prefer VS Code or the command line?

The same folders work there too. Open the folder, start Claude Code, type the prompts. If you use an AI assistant that runs commands, consider [House Rules](https://github.com/LogicTalkAI/houserules), a free safety net that blocks dangerous commands and keeps passwords out of your project.
